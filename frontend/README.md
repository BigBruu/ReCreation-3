# TheReCreation Frontend

React 19 Frontend für das 4X Weltraum-Strategiespiel *TheReCreation*.

## 📱 Features
* **Observatorium**: 7×7 Galaxie-Raster mit Touch-Gesten (Wischen/Swipe, Zwei-Finger-Pinch), Zoomtasten und D-Pad.
* **Werft & Rechner**: Modaler Raumschiff-Konfigurator mit dynamischer Wertberechnung und Komponenten-Auswahl.
* **Raumhafen**: Flottenübersicht, Flottenbewegung mit Klick-Auto-Fill aus dem Observatorium, Haltungssteuerung (Defensiv/Aggressiv).
* **Einrichtungen**: Übersicht und Ausbau der Ressourcen- und Spezialgebäude.
* **Technologie**: Forschungsübersicht für Antriebe, Schilde und Waffen.
* **Admin-Panel**: Umfassende Spiel- und Rundenverwaltung.

## 🚀 Skripte
* `yarn start`: Startet den React-Entwicklungsserver.
* `yarn build`: Erstellt ein optimiertes Produktions-Bundle.
* `yarn test`: Führt Frontend-Tests aus.
